*REPORT ON JAVASCRIPT*

*1.0 Introduction*
JavaScript is a high-level programming language mainly used to make web pages interactive. It is one of the core technologies of the World Wide Web, alongside HTML and CSS. While HTML structures the page and CSS styles it, JavaScript adds behavior.

*2.0 History*
JavaScript was created in 1995 by Brendan Eich at Netscape. It was first called LiveScript, then renamed to JavaScript. It is not related to Java language. Now it is managed by ECMA International under the name ECMAScript.

*3.0 Where JavaScript is Used*
a) *Frontend Development:* To make buttons, forms, sliders, and pop-ups work in the browser.
b) *Backend Development:* Using http://Node.js, JavaScript can run on the server like you were trying to do with MySQL.
c) *Mobile Apps:* Frameworks like React Native use JavaScript to build Android and iOS apps.
d) *Data Visualization:* Libraries like http://Chart.js can draw boxplots and graphs like you did in Python.

*4.0 Key Features*
- Lightweight and easy to learn
- Runs directly in the browser, no installation needed
- Event-driven and interactive
- Works with HTML and CSS
- Large community and many libraries (React, Vue, Angular)

*5.0 Example of Simple Code*
// Print outliers like in Python
let labHours = [10, 12, 15, 20, 25, 200]; // 200 is outlier

function findOutlier(data) {
    data.sort((a,b) => a-b);
    console.log("Highest value (possible outlier): " + data[data.length-1]);
}

findOutlier(labHours);
*6.0 Advantages and Disadvantages*
*Advantages:*
- Fast, runs immediately in browser
- Easy to connect to MySQL using http://Node.js
- Same language for frontend and backend

*Disadvantages:*
- Security issues if not written well
- Different browsers may show results differently
- Can be disabled by user in browser

*7.0 Conclusion*
JavaScript is a very important language for any student doing web development or data science projects. For your project, you can use Python for analysis (boxplots) and JavaScript + MySQL for building a system to store and display the results.
